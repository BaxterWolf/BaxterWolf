### Low-level Windows, reverse engineering, and how things work underneath

I mostly write C and C++ on Windows: drivers, process internals, and tools that talk to the OS directly. Before that it was embedded C on STM32 and circuit boards I assembled myself. Heading toward red teaming and malware analysis.

#### Projects

**[Hadal](https://github.com/BaxterWolf/Hadal)**: a Tailscale-only remote for Windows. Screen streaming, touchpad, files and power control from an Android phone. C++ service and tray app, Kotlin app, fuzzed with libFuzzer and ASan.
